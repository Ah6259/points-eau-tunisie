# Guide — Points d'eau Tunisie (pour Ahmed)
- Voir le site : https://ah6259.github.io/points-eau-tunisie/
- Rien à faire au quotidien : les points signalés apparaissent seuls (toutes les 2 h), « à confirmer » jusqu'à ce qu'un 2e
  visiteur les confirme ; un point dont plusieurs visiteurs disent « n'existe plus » disparaît.
- Les signalements arrivent aussi dans le tableau Google des prix du site des Eaux (lignes « POINT »).
- À décider : faut-il une partie payante ? (rien pour l'instant : site d'entraide).
- Le monde entier (09/10/2026) : au-dessus de la carte, le bandeau « 🌍 Le monde entier est sur la carte » (chercher une ville,
  villes d'exemple, « Voir le monde ») ; les villes d'exemple sont les boutons `data-ville-ex` de `index.html`.
