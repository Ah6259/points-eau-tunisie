มาเญลและบ่อน้ำในตูนิเซีย

นับหลายศตวรรษมาแล้ว ในตูนิเซียผู้คนเก็บน้ำฝนไว้ในบ่อเก็บน้ำ (มาเญล เฟสกียะฮ์) ขุดบ่อน้ำ และแบ่งน้ำของโอเอซิสตามเวลาอย่างแม่นยำ เทคนิคเหล่านี้หลายอย่างยังใช้อยู่ในปัจจุบัน นี่คือสาระสำคัญ และลิงก์ที่น่าเชื่อถือสำหรับศึกษาเพิ่มเติม ก่อสร้าง หรือบูรณะ

มาเญลโดยย่อ

  • บ่อเก็บน้ำใต้ดิน (ماجل) ที่เก็บน้ำฝนจากหลังคา ลานบ้าน หรือพื้นที่ลาดเอียง («อิมพลูเวียม»)
  • สามส่วน: พื้นผิวรับน้ำ บ่อเล็กสำหรับให้โคลนตกตะกอน แล้วจึงเป็นถังเก็บที่ขุดลงในดินและฉาบให้กันน้ำซึม
  • ที่เจรบาและภาคใต้ มาเญลประจำบ้านอยู่คู่กับเฟสกียะฮ์ บ่อเก็บน้ำขนาดใหญ่ที่มักเป็นของสาธารณะ หลังคาและลานบ้านจะถูกทาปูนขาวก่อนฤดูฝนเพื่อให้น้ำสะอาด
  • ยังมีประโยชน์ในปัจจุบัน: เนื่องจากภัยแล้ง รัฐให้สินเชื่อปลอดดอกเบี้ยเพื่อสร้างมาเญล และสมาคมต่าง ๆ บูรณะบ่อเก็บน้ำสาธารณะ

น้ำในมาเญลไม่ได้รับการตรวจสอบ: โปรดต้มหรือกรองก่อนดื่ม

มาเญลและเฟสกียะฮ์ของเจรบาและภาคใต้

  • AJEM — Fesguietna FR : การสำรวจ แผนที่ และการบูรณะบ่อเก็บน้ำสาธารณะของเจรบา (มาเญล 212 แห่งบนแผนที่ของเรามาจากพวกเขา)
  • Webmanagercenter FR : «มาเญล สมบัติจากบรรพบุรุษ» — ทำงานอย่างไร
  • Vikidia FR : บ่อเก็บน้ำของเจรบาอธิบายอย่างเข้าใจง่าย (มาเญล เฟสกียะฮ์)
  • Vikidia FR : เมนเซล บ้านแบบดั้งเดิมของเจรบา พร้อมบ่อเก็บน้ำและบ่อน้ำ
  • AllAfrica FR : บ่อเก็บน้ำโบราณของเจรบา มรดกและเครื่องมือรับมือกับสภาพภูมิอากาศ

วิธีสร้างมาเญล

  • WOCAT — Cistern (Tunisia) EN : เอกสารทางเทคนิคฉบับสมบูรณ์ (สถาบันภูมิภาคแห้งแล้งแห่งเมเดนีน): พื้นผิวรับน้ำ บ่อตกตะกอน ถังเก็บ ขนาด ค่าใช้จ่าย และการดูแลรักษา
  • FAO EN : เทคนิคการเก็บน้ำในตูนิเซีย และผลต่อดินและน้ำ
  • Kapitalis FR : «เมื่อเผชิญภาวะขาดแคลนน้ำ ชาวตูนิเซียหันไปใช้วิธีของบรรพบุรุษ» — หลังคาทาปูนขาว บ่อเก็บน้ำ คำแนะนำ

บ่อน้ำและโอเอซิส

  • IRCICA — Bi'r Barouta EN : บ่อน้ำอันเลื่องชื่อของไครวน ซึ่งน้ำถูกตักขึ้นมาด้วยระหัดวิดน้ำที่หมุนโดยอูฐ
  • La Presse FR : บีร์ บาร์รูตา ในปัจจุบัน: ประวัติ ตำนาน และสภาพของโบราณสถาน
  • Webmanagercenter FR : «เบลด เอล อาบาร์» (ดินแดนแห่งบ่อน้ำ): โครงการฟื้นฟูบ่อน้ำในทะเลทรายตูนิเซีย
  • Webdo FR : อิบน์ ชับบาต «ปรมาจารย์แห่งน้ำ» ของเจริด และการแบ่งน้ำของโอเอซิสตามเวลา
  • UNESCO EN : โอเอซิสกาเบส โอเอซิสริมทะเลแห่งเดียว อยู่ในบัญชีรายชื่อเบื้องต้นของมรดกโลก
  • Hydria Project EN : น้ำในคาร์เธจสมัยโรมันและในตูนิส: บ่อเก็บน้ำ บ่อน้ำ และกังหันวิดน้ำ

การเก็บน้ำฝนบนผืนดินภาคใต้

  • WOCAT — Jessour EN : เญสซูร์ในเทือกเขาเมเดนีน: กำแพงเตี้ย ๆ ที่กักน้ำและดินไว้เพื่อปลูกมะกอกและมะเดื่อ
  • WOCAT — Tabia EN : ตาเบียบริเวณเชิงเขา: คันดินที่เก็บน้ำไหลบ่าและเติมน้ำใต้ดิน

ยังใช้อยู่ในปัจจุบัน

  • Webmanagercenter FR : สินเชื่อปลอดดอกเบี้ยของรัฐเพื่อสร้างมาเญล (กฎหมายงบประมาณ) ซึ่งได้รับการต่ออายุ
  • African Manager FR : WWF เสนอให้ฟื้นฟูมาเญลเพื่อรับมือกับการเปลี่ยนแปลงสภาพภูมิอากาศ
  • Kapitalis FR : «เบลด อัล อาบาร์» โครงการส่งเสริมคุณค่าของบ่อน้ำในทะเลทรายตูนิเซีย
